# Piano Sync — 화면 패턴

## 1. 전체 구조

```
AppBar (브랜드 · 설정 · 새 프로젝트)
Workbench
  ├─ Rail (데스크톱) / Top step bar (모바일)
  └─ Main
       ├─ Step 1: 소스 · 정렬
       └─ Step 2: 내보내기
StatusBar
```

설정은 별도 화면이 아니라 **모달/하단 시트**다. 작업 맥락을 유지한다.

## 2. Step 1 — 소스 · 정렬

순서:
1. 패널 헤더(제목·설명) + `분석 시작`
2. 소스 목록 (SourceRow)
3. 영상 추가 dropzone
4. 분석 설정 카드(품질 · Gemini 보조)
5. RunBar(분석 중에만)
6. 분석 요약 카드
7. 정렬 타임라인 카드(데이터 없으면 차트 숨김 + EmptyState)
8. 구간 카드(SegmentRow 목록 + 경고)

상태:
- **초기/빈 상태**: 소스 없음, 타임라인 차트 숨김, 안내 문구만.
- **업로드 중**: 소스 행 진행 바, 분석 버튼 비활성.
- **분석 중**: RunBar 표시, 취소 가능, 상태바 진행률.
- **완료**: 요약 카드, 타임라인/구간 표시, 분석 버튼 재실행 가능.
- **오류**: 상태바 오류 + 토스트, RunBar 숨김.

## 3. Step 2 — 내보내기

순서:
1. 패널 헤더 + `최종 영상 생성`
2. 렌더 진행(진행 중에만)
3. 전환 설정 카드(모드·효과·오디오·시작 영상·전환 주기·온셋 스냅)
4. 출력 설정 카드(출력 크기·FPS·CRF·파일명) — 출력 크기 기본값은 `원본 해상도`(소스의 해상도·방향),
   이후 세로 9:16 → 가로 16:9 → 정사각/4:5 순으로 정렬해 모바일 세로 작업을 먼저 노출
5. 글자 넣기 카드(`영상에 글자 넣기`) — 글자 textarea + 글꼴(`#overlayFont`)/위치/크기/색상,
   비우면 렌더에 포함하지 않음. 글꼴은 설치된 폰트 스캔(한글 지원 먼저) + `직접 지정` 경로 입력
6. 결과 카드(빈 상태 또는 영상 + 다운로드)

상태:
- **빈 결과**: `결과 없음` EmptyState, 다운로드 숨김.
- **렌더 중**: 진행 바/퍼센트, 버튼 비활성, 취소 불가(현재).
- **완료**: 통계 + `<video>` + 다운로드.
- **오류**: 토스트 + 상태바 오류.

## 4. 설정 시트

- 진입: AppBar 설정(⚙).
- 섹션: 화면 테마(자동/다크/라이트), Gemini API 키.
- 모바일: 하단 시트. 데스크톱: 중앙 모달.
- 닫기: 닫기 버튼 / ESC / 배경 탭(브라우저 기본).

## 5. 반응형 규칙

| 폭 | 레이아웃 |
|---|---|
| ≥941px | 좌측 레일 + 2열(.cols) |
| 761–940px | 좌측 레일 + 1열 스택 |
| ≤760px | 상단 스텝 바, 1열, 시트형 설정, 태그라인 숨김 |

- 320px까지 가로 오버플로우 없음(검증).
- 안전 영역: AppBar 상단/좌우, StatusBar 하단, 시트 하단.
- `100dvh` 사용.

## 6. 테마

- 다크/라이트/자동. 첫 페인트 전 적용.
- 캔버스(타임라인)도 테마 팔레트로 재드로잉.
- 라이트에서 primary 버튼/토글/세그먼트는 반전 처리.

## 7. 콘텐츠 길이/변화 대응

- 파일명/메시지는 ellipsis 처리, 레이아웃은 grid로 밀림 방지.
- 구간 목록은 최대 높이 + 내부 스크롤.
- 긴 목록(소스 5개)·작은 화면에서 세로 스크롤 유지.
- 키보드 노출 시: 입력은 카드 내부에 있어 뷰포트 스크롤로 접근 가능(별도 고정 바 없음).

## 8. 금지 패턴

- 빈 데이터에서 빈 차트를 그려두지 않는다.
- 모바일에서 태그라인·보조 레일로 상단을 압박하지 않는다.
- 중복된 설정을 두 단계에 나누지 않는다(전환 설정은 Step 2 한 곳).
